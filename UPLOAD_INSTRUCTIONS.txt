📤 QUICK UPLOAD STEPS (خطوات الرفع السريعة):
════════════════════════════════════════════════════════════════════

STEP 1: Open FileZilla
─────────────────────
Launch FileZilla application

STEP 2: Connect to Server
──────────────────────────
File → Site Manager → New Site

Enter your server details:
  Host: [Your Server IP/Domain]
  Protocol: SFTP (Port 22) or FTP (Port 21)
  User: [Your server username]
  Pass: [Your server password]

Click "Connect"

STEP 3: Navigate to Upload Folder
──────────────────────────────────
On the server side (right panel), navigate to:

  /home/username/public/driver/
  OR
  /public_html/driver/
  OR
  /var/www/html/driver/

(Ask your hosting provider if unsure)

STEP 4: Upload All Files
────────────────────────
Drag and drop or upload these 4 files:

  ✓ driver.js
  ✓ driver.css
  ✓ index.html
  ✓ .env.local

Make sure all files are uploaded successfully!

STEP 5: Set Permissions
───────────────────────
Right-click each file → Properties → Permissions

Set to: 644 (rw-r--r--)

This ensures proper file access.

STEP 6: Restart Your Server
────────────────────────────
Connect via SSH or use your hosting control panel:

  Command: pm2 restart app
  Or: systemctl restart app
  Or use cPanel/Plesk to restart

Wait 30 seconds for server to restart.

🆘 TROUBLESHOOTING (حل المشاكل الشائعة):
════════════════════════════════════════════════════════════════════

ISSUE: Cannot connect to server in FileZilla
SOLUTION: Check host, port, username, and password
         اتصل بمضيف الويب للتحقق من البيانات

ISSUE: Files won't upload
SOLUTION: Check folder permissions and disk space
         تأكد من أن لديك مساحة كافية والأذونات صحيحة

ISSUE: App doesn't work after upload
SOLUTION: Restart server, check .env.local is uploaded
         تأكد من وجود .env.local وأعد تشغيل السيرفر

ISSUE: Getting permission denied errors
SOLUTION: Set file permissions to 644 with FileZilla
         استخدم FileZilla لتعيين الأذونات
